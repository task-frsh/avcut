## 설치

### 포터블 버전 (권장)
1. [Releases 페이지](https://github.com/yourusername/avicut/releases)에서 `AviCut-vX.X.X-win64.zip` 다운로드
2. 원하는 폴더에 압축 해제 (예: `C:\Tools\AviCut`)
3. `AviCut.exe` 실행 - 설치 불필요!

### 요구사항
- Windows 10 또는 Windows 11 (64비트)
- 최소 4GB RAM
- 약 150MB 디스크 공간

## 동영상 추가

### 방법 1: 드래그 앤 드롭
1. 파일 탐색기 열기
2. 동영상 파일 선택
3. AviCut 창으로 끌어다 놓기
4. 드롭 영역이 하이라이트될 때 놓기

### 방법 2: 파일 선택 버튼
1. "파일 선택" 버튼 클릭
2. 동영상 파일 찾아보기
3. 하나 또는 여러 파일 선택
4. "열기" 클릭

### 방법 3: 폴더 선택 버튼
1. "폴더 선택" 버튼 클릭
2. 동영상이 있는 폴더 찾아보기
3. "폴더 선택" 클릭
4. 해당 폴더의 모든 동영상 파일이 추가됨

### 파일 관리
파일이 추가되면 목록이 표시됩니다:
- **파일 이름**: 동영상 파일 이름
- **길이**: 동영상 길이
- **제거 (×)**: 개별 파일 제거
- **전체 삭제**: 모든 파일 제거

## 옵션 설정

### 분할 단위
각 세그먼트의 길이를 분 단위로 입력:
- 최소: 1분
- 최대: 999분
- 기본값: 5분

**예시:**
- 원본 동영상: 15분
- 분할 단위: 5분
- 결과: 3개 세그먼트 (5분 + 5분 + 5분)

### 출력 폴더
분할된 동영상을 저장할 위치 선택:
1. "찾아보기" 버튼 클릭
2. 폴더 선택
3. 또는 경로 직접 입력

**기본 위치:** `C:\Users\[사용자이름]\Videos\AviCut_Output`

## 동영상 분할

1. 위 방법 중 하나로 **동영상 추가**
2. **분할 단위 설정** (예: 5분)
3. **출력 폴더 선택**
4. **"분할 시작" 클릭**

### 처리 중
다음이 표시됩니다:
- 현재 처리 중인 파일
- 현재 파일 진행률
- 전체 진행률 (예: 5개 중 2번째 파일 "2 / 5")
- 취소 버튼

### 취소하기
"취소" 버튼을 클릭하면 작업이 중단됩니다. 이미 생성된 세그먼트는 유지됩니다.

분할이 완료되면 결과 대화상자가 나타납니다:

```

│  ✓ 분할 완료!                               │
├─────────────────────────────────────────────┤
│  요약:                                      │
│    처리된 파일: 3                           │
│    성공: 3                                  │
│    실패: 0                                  │
│    생성된 세그먼트: 12                       │
├─────────────────────────────────────────────┤
│  출력 파일:                                 │
│    ✓ video1_part001.mp4                     │
│    ✓ video1_part002.mp4                     │
│    ✓ video1_part003.mp4                     │
│    ...                                      │
├─────────────────────────────────────────────┤
│  [출력 폴더 열기]  [더 분할하기]              │
└─────────────────────────────────────────────┘
```

### 출력 파일 이름 규칙
파일은 파트 번호와 함께 저장됩니다:
```
원본: my_video.mp4
출력: my_video_part001.mp4
      my_video_part002.mp4
      my_video_part003.mp4
```

## 언어 설정

AviCut은 영어와 한국어를 지원합니다.

### 언어 전환
1. 오른쪽 상단의 언어 버튼 찾기
2. "English"를 클릭하면 영어로 전환
3. "한국어"를 클릭하면 한국어로 전환

인터페이스가 즉시 업데이트됩니다.

## 문제 해결

### "FFmpeg를 찾을 수 없습니다" 오류
FFmpeg는 AviCut에 번들로 제공됩니다. 이 오류가 표시되면:
1. 압축 파일을 완전히 풀었는지 확인
2. `AviCut.exe` 옆에 `ffmpeg` 폴더가 있는지 확인
3. 릴리즈 패키지 다시 다운로드 시도

### 동영상이 로드되지 않음
- 파일 형식이 지원되는지 확인
- 다른 플레이어에서 먼저 재생해보기
- 파일이 손상되었을 수 있음

### 분할 실패
일반적인 원인:
- 디스크 가득 참 - 출력 폴더 공간 확보
- 파일 잠김 - 파일을 사용 중인 다른 프로그램 종료
- 권한 거부 - 관리자 권한으로 실행 시도

### 앱이 시작되지 않음
1. Windows 10/11 64비트인지 확인
2. 관리자 권한으로 실행 시도
3. Windows 이벤트 뷰어에서 오류 확인

## 자주 묻는 질문

### Q: 분할할 때 화질 손실이 있나요?
**A:** 없습니다! AviCut은 FFmpeg의 "copy" 모드를 사용하여 비디오와 오디오 스트림을 재인코딩 없이 복사합니다. 화질 손실이 전혀 없습니다.

### Q: 정확한 프레임 위치에서 자를 수 있나요?
**A:** AviCut은 비디오 무결성을 유지하기 위해 가장 가까운 키프레임에서 자릅니다. 정확한 프레임 단위 편집은 전문 비디오 편집기 사용을 권장합니다.

### Q: 마지막 세그먼트가 왜 짧나요?
**A:** 동영상 길이가 분할 단위로 나누어 떨어지지 않으면 마지막 세그먼트가 짧아집니다. 예: 12분 동영상을 5분으로 분할하면 5분, 5분, 2분이 됩니다.

### Q: 각 세그먼트마다 다른 길이를 선택할 수 있나요?
**A:** 현재 AviCut은 균일한 길이를 사용합니다. 사용자 정의 세그먼트 길이는 LosslessCut 사용을 권장합니다.

### Q: 내 동영상이 안전한가요?
**A:** 네! AviCut은 원본 파일을 절대 수정하지 않습니다. 출력 폴더에 새 파일만 생성합니다.

### Q: 최대 파일 크기는?
**A:** 하드 제한이 없습니다. AviCut은 사용 가능한 디스크 공간에 의해서만 제한되며 모든 크기의 파일을 처리할 수 있습니다.
